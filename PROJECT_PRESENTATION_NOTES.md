# DEBATE ARENA - PROJECT PRESENTATION NOTES

## 🎯 PROJECT OVERVIEW
**Project Name:** Debate Arena - Challenge AI, Sharpen Your Mind  
**Type:** Interactive AI-Powered Debate Platform  
**Purpose:** Real-time debate practice with AI opponent to improve argumentation skills

---

## 🛠️ TECHNOLOGIES USED

### **Frontend Framework & Core**
- **React 18.3.1** - Modern UI library with hooks
- **TypeScript** - Type-safe JavaScript development
- **Vite** - Fast build tool and development server
- **React Router DOM** - Client-side routing

### **UI/UX Libraries**
- **Tailwind CSS** - Utility-first CSS framework
- **shadcn/ui** - Modern component library
- **Radix UI** - Accessible component primitives
- **Lucide React** - Beautiful icon library
- **Class Variance Authority** - Component styling variants

### **State Management & Data**
- **React Hooks** (useState, useEffect, useRef)
- **TanStack React Query** - Server state management
- **React Hook Form** - Form handling
- **Zod** - Schema validation

### **AI Integration**
- **Google Gemini 2.0 Flash API** - AI conversation engine
- **Custom debate logic** - Position-based argument generation

### **Additional Features**
- **Dark/Light Theme** - next-themes
- **Toast Notifications** - Sonner
- **Responsive Design** - Mobile-first approach
- **Real-time Timer** - Debate session management

---

## 🏗️ PROJECT ARCHITECTURE

### **Component Structure**
```
src/
├── components/ui/          # Reusable UI components
├── hooks/                  # Custom React hooks
├── lib/                    # Utility functions
├── pages/                  # Main page components
│   ├── Index.tsx          # Main debate interface
│   └── NotFound.tsx       # 404 page
├── App.tsx                # Root component
└── main.tsx               # Application entry point
```

### **Key Features Implemented**
1. **Splash Screen** - Animated welcome screen
2. **Topic Selection** - Predefined + custom topics
3. **Difficulty Levels** - Beginner, Intermediate, Advanced
4. **Position Choice** - For/Against stance selection
5. **Real-time Chat** - Message exchange with AI
6. **Timer System** - 10-minute debate sessions
7. **Score Tracking** - Argument count monitoring
8. **Results Summary** - Post-debate statistics
